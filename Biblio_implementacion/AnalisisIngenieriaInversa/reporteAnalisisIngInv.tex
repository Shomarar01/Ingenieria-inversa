\section{Introducción}
En el entorno educativo actual, la administración eficiente de la información académica es fundamental para el correcto funcionamiento de una institución. Los procesos de asignación docente, control de matrículas, programación de horarios en aulas físicas y el seguimiento del rendimiento de los alumnos generan un volumen de datos que requiere centralización. Este documento detalla el diseño e implementación del modelo de datos para el sistema denominado "escuela".

\section{Descripción del problema}
La institución carecía de un mecanismo unificado para relacionar sus diferentes áreas operativas. Los departamentos académicos funcionaban de manera aislada a la asignación de espacios físicos (aulas), lo que provocaba riesgos de duplicidad de horarios o sobrecupos. Asimismo, el registro de las notas finales de los estudiantes dependía de actas manuales propensas a errores. Se requería diseñar una base de datos relacional robusta que garantizara la consistencia mediante restricciones de integridad.

\subsection{Análisis y diseño}
Mediante ingeniería inversa aplicada al esquema, se determinó una estructura compuesta por 8 entidades principales normalizadas para evitar redundancias:
\begin{itemize}
    \item \textbf{departamentos:} Almacena las áreas académicas de la institución.
    \item \textbf{profesores:} Registra al personal docente adscrito a un departamento específico (Relación 1 a Muchos).
    \item \textbf{cursos:} Lista de materias que son impartidas por un profesor titular.
    \item \textbf{estudiantes:} Contiene la información de los alumnos matriculados.
    \item \textbf{inscripciones:} Entidad intermedia que rompe la relación Muchos a Muchos entre estudiantes y cursos, registrando la fecha del alta.
    \item \textbf{aulas:} Infraestructura física con control de capacidad.
    \item \textbf{horarios:} Modela la asignación de los cursos en un aula, día y rango de horas específicos.
    \item \textbf{notas:} Registra las calificaciones cuantitativas finales vinculadas directamente a una inscripción.
\end{itemize}

\subsection{Implementación y validación}
A continuación, se presentan los scripts estructurados para el despliegue del sistema y la posterior validación del modelo mediante la carga de datos iniciales.

\begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Script de creación de las tablas para el modelo de datos (DDL)}]
-- Crear Base de Datos
CREATE DATABASE IF NOT EXISTS escuela;
USE escuela;

-- Tabla de Departamentos
CREATE TABLE departamentos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100) NOT NULL
);

-- Tabla de Profesores
CREATE TABLE profesores (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100),
    apellido VARCHAR(100),
    email VARCHAR(100),
    id_departamento INT,
    FOREIGN KEY (id_departamento) REFERENCES departamentos(id)
);

-- Tabla de Cursos
CREATE TABLE cursos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100),
    creditos INT,
    id_profesor INT,
    FOREIGN KEY (id_profesor) REFERENCES profesores(id)
);

-- Tabla de Estudiantes
CREATE TABLE estudiantes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100),
    apellido VARCHAR(100),
    email VARCHAR(100),
    fecha_nacimiento DATE
);

-- Tabla de Inscripciones
CREATE TABLE inscripciones (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_estudiante INT,
    id_curso INT,
    fecha_inscripcion DATE,
    FOREIGN KEY (id_estudiante) REFERENCES estudiantes(id),
    FOREIGN KEY (id_curso) REFERENCES cursos(id)
);

-- Tabla de Aulas
CREATE TABLE aulas (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(50),
    capacidad INT
);

-- Tabla de Horarios
CREATE TABLE horarios (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_curso INT,
    id_aula INT,
    dia_semana VARCHAR(15),
    hora_inicio TIME,
    hora_fin TIME,
    FOREIGN KEY (id_curso) REFERENCES cursos(id),
    FOREIGN KEY (id_aula) REFERENCES aulas(id)
);

-- Tabla de Notas
CREATE TABLE notas (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_inscripcion INT,
    nota DECIMAL(4,2),
    FOREIGN KEY (id_inscripcion) REFERENCES inscripciones(id)
);
\end{lstlisting}

\section{Preguntas del Modelo}
A continuación, se listan las interrogantes planteadas para evaluar la integridad y funcionalidad del esquema de la base de datos \textit{escuela}:

\begin{enumerate}
    \item ¿Cuáles son los estudiantes inscritos en el curso "Álgebra"?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 1: Estudiantes inscritos en Álgebra}]
        SELECT CONCAT(e.nombre, ' ', e.apellido) AS Nombre_estudiante
        FROM estudiantes e
        INNER JOIN inscripciones i ON e.id = i.id_estudiante
        INNER JOIN cursos c ON i.id_curso = c.id
        WHERE c.nombre = 'Algebra';
    \end{lstlisting}
    \begin{verbatim}
    +-------------------+
    | Nombre_estudiante |
    +-------------------+
    | Juan Pérez        |
    | María Gómez       |
    +-------------------+
    \end{verbatim}


    \item ¿Qué cursos imparte el profesor Pedro Martínez?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 2: Cursos impartidos por Pedro Martínez}]
        SELECT c.nombre AS Nombre_curso,
            CONCAT(p.nombre, ' ', p.apellido) AS Nombre_profesor
        FROM cursos c
        INNER JOIN profesores p ON c.id_profesor = p.id
        WHERE p.nombre = 'Pedro' AND p.apellido = 'Martínez';
    \end{lstlisting}
    \begin{verbatim}
        +--------------+-----------------+
        | Nombre_curso | Nombre_profesor |
        +--------------+-----------------+
        | Programación | Pedro Martínez  |
        +--------------+-----------------+
    \end{verbatim}

    \item ¿Cuántos estudiantes están inscritos en cada curso?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 3: Total de estudiantes por curso}]
        SELECT c.nombre,
            COUNT(i.id_estudiante) AS total_estudiantes
        FROM cursos c
        LEFT JOIN inscripciones i ON c.id = i.id_curso
        GROUP BY c.id, c.nombre;
    \end{lstlisting}
    \begin{verbatim}
    +--------------+-------------------+
    | Nombre_curso | Total_estudiantes |
    +--------------+-------------------+
    | Álgebra      |                 2 |
    | Biología     |                 1 |
    | Historia     |                 1 |
    | Programación |                 1 |
    | Física       |                 1 |
    +--------------+-------------------+
    \end{verbatim}


    \item ¿Cuál es el promedio de notas por curso?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 4: Promedio de notas por curso}]
        SELECT c.nombre AS Nombre_curso,
            AVG(n.nota) AS Promedio
        FROM cursos c
        INNER JOIN inscripciones i ON c.id = i.id_curso
        INNER JOIN notas n ON i.id = n.id_inscripcion
        GROUP BY c.nombre;
    \end{lstlisting}
    \begin{verbatim}
    +--------------+----------+
    | Nombre_curso | Promedio |
    +--------------+----------+
    | Álgebra      | 8.000000 |
    | Biología     | 9.000000 |
    | Historia     | 6.800000 |
    | Programación | 9.200000 |
    | Física       | 7.000000 |
    +--------------+----------+
    
    \end{verbatim}



    \item Lista de estudiantes con notas mayores a 8.0
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 5: Estudiantes con nota mayor a 8.0}]
        SELECT CONCAT(e.nombre, ' ', e.apellido) AS Nombre_estudiante,
            n.nota AS Calificacion
        FROM estudiantes e
        INNER JOIN inscripciones i ON e.id = i.id_estudiante
        INNER JOIN notas n ON i.id = n.id_inscripcion
        WHERE n.nota > 8.0;
    \end{lstlisting}
    \begin{verbatim}
    +-------------------+--------------+
    | Nombre_estudiante | Calificacion |
    +-------------------+--------------+
    | Juan Pérez        |         8.50 |
    | Juan Pérez        |         9.00 |
    | Carlos Sánchez    |         9.20 |
    +-------------------+--------------+
    \end{verbatim}


    \item ¿Qué cursos tienen más de una inscripción?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 6: Cursos con más de una inscripción}]
        SELECT c.nombre AS Nombre_curso,
            COUNT(i.id) AS Total_inscripciones
        FROM cursos c
        INNER JOIN inscripciones i ON c.id = i.id_curso
        GROUP BY c.nombre
        HAVING COUNT(i.id_estudiante) > 1;
    \end{lstlisting}
    \begin{verbatim}
        +--------------+---------------------+
        | Nombre_curso | Total_inscripciones |
        +--------------+---------------------+
        | Álgebra      |                   2 |
        +--------------+---------------------+
    \end{verbatim}


    \item ¿Qué profesores pertenecen al departamento de 'Ingeniería'?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 7: Profesores del departamento Ingeniería}]

    \item ¿Cuáles son los cursos programados los lunes?

        SELECT c.nombre AS Nombre_curso,
            h.dia_semana AS Dia

        INNER JOIN horarios h ON c.id = h.id_curso

    \end{lstlisting}
    \begin{verbatim}
        +--------------+-------+
        | Nombre_curso | Dia   |
        +--------------+-------+
        | Álgebra      | Lunes |
        +--------------+-------+
            \end{verbatim}                  


    \item ¿Qué aulas tienen una capacidad mayor a 25?

    \begin{verbatim}

    | Nombre_aula       | Capacidad |

    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 10: Cursos con aula y horario}]

    \item ¿Qué estudiantes tiene la nota más alta y en qué cursos?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 11: Estudiantes con nota máxima}]
        SELECT CONCAT(e.nombre, ' ', e.apellido) AS Nombre_estudiante,
            c.nombre AS Nombre_curso,
            n.nota AS Nota_maxima

        INNER JOIN inscripciones i ON e.id = i.id_estudiante
        INNER JOIN cursos c ON i.id_curso = c.id

    \end{lstlisting}
    \begin{verbatim}

    \begin{verbatim}

    \item ¿Qué estudiantes están inscritos en más de un curso?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 14: Estudiantes con más de un curso}]
        SELECT CONCAT(e.nombre, ' ', e.apellido) AS Nombre_estudiante,
            COUNT(i.id_curso) AS Cursos_inscritos
        FROM estudiantes e
        INNER JOIN inscripciones i ON e.id = i.id_estudiante
        GROUP BY e.id, Nombre_estudiante
        HAVING COUNT(i.id_curso) > 1;
    \end{lstlisting}
    \begin{verbatim}
    +-------------------+------------------+
    | Nombre_estudiante | Cursos_inscritos |
    +-------------------+------------------+
    | Juan Pérez        |                2 |
    | María Gómez       |                2 |
    +-------------------+------------------+
    \end{verbatim}


    \item ¿Cuál es el curso con menor promedio de notas?
    \begin{lstlisting}[language=SQL, frame=single, numbers=left, caption={Consulta 15: Curso con menor promedio de notas}]
        SELECT c.nombre AS Nombre_curso,
            AVG(n.nota) AS Promedio
        FROM cursos c
        INNER JOIN inscripciones i ON c.id = i.id_curso
        INNER JOIN notas n ON i.id = n.id_inscripcion
        GROUP BY c.nombre
        ORDER BY Promedio ASC
        LIMIT 1;
    \end{lstlisting}
    \begin{verbatim}
    +--------------+----------+
    | Nombre_curso | Promedio |
    +--------------+----------+
    | Historia     | 6.800000 |
    +--------------+----------+
    \end{verbatim}
\end{enumerate}

\section{Conclusiones}
Hacer la ingeniería inversa de esta base de datos nos permitió entender muy bien cómo se conecta toda la información de la escuela. Al analizar las tablas y resolver las 15 preguntas, quedó claro que las llaves foráneas (\textit{Foreign Keys}) son la pieza clave para que todo funcione en orden; por ejemplo, evitan que se registre una calificación de un alumno que no existe o que se empalmen los horarios en los salones. En conclusión, el sistema está muy bien organizado, no duplica datos innecesarios y es completamente confiable para llevar el control escolar de los estudiantes y profesores.
